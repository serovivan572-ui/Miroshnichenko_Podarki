# Запуск и демо-данные

Версия 1.0 · проект «Подарок» · Мирошниченко С. В. · 4ИСП-07.

## Открыть прототип

Скачайте проект, распакуйте его и откройте `prototype/podarok/dist/index.html` в Chrome или Edge. Приложение работает без сервера, установки и сборки.

На первом экране открыт демо-аккаунт с четырьмя контактами. Для регистрации нового аккаунта выберите **Настройки → Выйти из аккаунта → Создать**. Кнопка **«Открыть демо»** на экране входа возвращает к учебному аккаунту.

Если проверяете форму входа, используйте `demo@podarok.example` и учебную строку длиной 12–128 символов, например `GiftPlan2026!`. Настоящая проверка пароля и отправка писем здесь имитируются; пароль не сохраняется.

## Данные и дата

Контакты, даты, идеи и планы сохраняются в `localStorage` под ключом `podarok-pr7-v1`. После обновления страницы записи остаются в том же браузере. В другом браузере или после переноса файлов состояние может отличаться.

Опорная дата — **27.10.2026**. Она зафиксирована для повторяемой проверки ближайших событий.

Для возврата к исходным примерам:

1. Откройте инструменты разработчика браузера: F12.
2. Перейдите в **Application → Local Storage** и выберите хранилище прототипа.
3. Удалите только ключ `podarok-pr7-v1` и обновите страницу.

Это удалит внесённые в прототип изменения. При запрете записи в хранилище приложение покажет ошибку и оставит заполненную форму открытой.
