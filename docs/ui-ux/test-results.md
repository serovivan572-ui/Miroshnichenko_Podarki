## Проблемы и исправления

| Проблема | Исправление | Проверка |
| --- | --- | --- |
| Значок поиска перекрывал начало подсказки | Повышен приоритет правила левого отступа поискового поля. | Мобильный снимок проверен визуально; повторный прогон — 12/12. |
| Переходы в тесте читались до отображения целевого экрана | Уточнены ожидания заголовков и уровень h1 для карточки; ожидание hash само по себе не подменяет готовность DOM. | Повторный полный прогон — 12/12. |
| Счётчик идей входил в доступное имя ссылки | В тесте навигация ищется по устойчивой текстовой части, а не полному имени с изменяемым числом. | SC-UI-04 пройден. |
| Кнопка удаления аккаунта есть и на странице и в диалоге | Проверка ограничена открытым dialog, чтобы нажать именно подтверждение. | SC-UI-05 пройден. |
| Несохранённая форма подарка могла быть покинута по ссылке | Добавлены предупреждения при переходе и закрытии/обновлении вкладки. | Статически проверено; основной прогон не подтверждает все варианты beforeunload. |
| Локальный HTTP-предпросмотр недоступен в окружении | Проверки выполнены открытием локального HTML в Chrome; прототип не зависит от сервера. | Фактический URL и среда записаны в test-results.json. |

Не проверено: реальные backend-тесты из ПР6; доставка e-mail; безопасность сессий; фото; реальные браузерные zoom/RTL и медленный replay анимаций; Safari/Firefox и реальные мобильные устройства. Адаптивность проверена в Chrome с изменением viewport. Результат относится к прототипу, а не подтверждает готовность приложения.
