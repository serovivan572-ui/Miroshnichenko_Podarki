# Пользовательские сценарии Подарок

Версия 1.0 от 27.10.2026. Сценарии адаптированы к MVP из ТЗ ПР3 и архитектуры ПР4.

## SC-UI-01 Создать личное пространство

Цель: создать личное пространство.

Начальное состояние: Посетитель находится на экране входа; новый e-mail отсутствует.

Действия: Регистрация → имя/e-mail/пароль 12–128 → создать → вход → главная → обновить. Ветвь: выйти → восстановить → новый пароль → вход.

Ожидаемый результат: Открыта главная нового аккаунта; список его контактов пуст, после обновления сеанс сохранён.

Требования: FR-01, FR-02. Проверка: TC-UI-01.

## SC-UI-02 Сохранить человека и памятную дату

Цель: сохранить человека и памятную дату.

Начальное состояние: Открыт демо-аккаунт; нового контакта ещё нет.

Действия: Контакты → добавить → имя/заметка → сохранить → добавить дату → ежегодное повторение → сохранить → события → поиск имени в другом регистре → повторно открыть.

Ожидаемый результат: Карточка, заметка и дата доступны после обновления; событие включено в ближайшие даты; поиск находит имя без учёта регистра.

Требования: FR-03, FR-04, FR-08. Проверка: TC-UI-02.

## SC-UI-03 Подготовить подарок и учесть расходы

Цель: подготовить подарок и учесть расходы.

Начальное состояние: Есть Анна и её событие; открыт её контакт.

Действия: Добавить подарок → название → план 3000/факт 2500 → статус «куплен» → сохранить → изменить факт на 3500/статус «подарен» → обновить → бюджет.

Ожидаемый результат: Сначала остаток 500 ₽, затем перерасход 500 ₽; название, суммы и статус сохранены.

Требования: FR-05, FR-06, FR-07. Проверка: TC-UI-03.

## SC-UI-04 Сохранить идею и выбрать получателя позже

Цель: сохранить идею и выбрать получателя позже.

Начальное состояние: Открыты входящие идеи; есть контакт Анна.

Действия: Сохранить «Термокружка» без получателя и цены → выбрать получателя → Анна → назначить → входящие → обновить карточку.

Ожидаемый результат: Идея исчезла из неназначенных; у Анны один план с сохранённым названием.

Требования: FR-09. Проверка: TC-UI-04.

## SC-UI-05 Изменить и безопасно удалить личные записи

Цель: изменить и безопасно удалить личные записи.

Начальное состояние: У Максима есть дата и план; есть другой контакт Анна.

Действия: Найти «Макс» → изменить имя → удалить → «Оставить» → снова удалить → подтвердить → проверить остальные контакты. Дополнительно: настройки → удалить аккаунт → подтверждение.

Ожидаемый результат: Отмена ничего не удаляет. Подтверждение удаляет Максима и связанные записи, Анна сохранена. Отдельное удаление аккаунта завершает сеанс.

Требования: FR-03, FR-10. Проверка: TC-UI-05.
